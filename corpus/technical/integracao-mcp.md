# Integração MCP

O Cursor (e outros hosts MCP) conectam ao [[servidor-mcp]] via stdio ou HTTP.

## Variáveis

- `KG_WORKSPACE` — raiz do corpus
- `DATABASE_URL` — Postgres

Tools planejadas: `kg_search`, `kg_expand`, `kg_pack` (Fase 5).

Ver `docs/07-servidor-mcp.md`.
